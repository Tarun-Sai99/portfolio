Projects

Four public repos. Each one starts from raw data and ends with findings.

  1. P1

    Formula 1 Performance Analysis

    MySQL 8 · CTEs · Window functions · Python

    Audits and cleans 114,000 rows of Formula 1 race data (1950 to 2026) into a typed relational model, then answers 22 questions about drivers, teams and how races are won. The main finding: pole position matters more than ever, with the pole sitter winning 55% of hybrid-era races against 36% in 1980 to 1999.

    View repo ↗

    36→55%pole-to-win rate

  2. P2

    Marvel vs DC Characters

    MySQL · Regex cleaning · Python

    Cleans and analyses about 23,000 comic book characters from the Marvel and DC wikias, using SQL for every step and Python only for the charts. Marvel is more than twice the size of DC (16,376 characters against 6,896), and the female share of new characters has roughly doubled over the decades but stalled near 30%.

    View repo ↗

    ~30%female share, stalled

  3. P3

    Historical Events Timeline

    Excel · Power Query · PivotTables · Slicers

    Profiles, cleans and visualises 1,088 major world events from 2600 BC to 2022, ending in an interactive dashboard with slicers. The record leans heavily toward recent history: 55% of events fall after 1945, and Europe accounts for one in four overall.

    View repo ↗

    55%events after 1945

  4. P4

    Video Game Sales

    Excel · Power Query · PivotCharts · Dashboard

    Analyses global video game sales from 1971 to 2018 end to end in Excel, from profiling and Power Query cleaning to PivotCharts and a slicer-driven dashboard. Sales peaked in 2008 at 538 million units, and Sports, Action and Shooter games make up about half of everything sold.
