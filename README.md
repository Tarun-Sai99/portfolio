# Portfolio: P. Tarun Sai, Data Analyst

A single-page portfolio website in plain HTML, CSS and a little JavaScript. No build step.

**Sections:** About, four data-analysis projects (SQL and Excel), and Contact.

## Open it

Download or clone this repo, then double-click `portfolio/index.html`. It opens in your browser.

Or serve it locally:

```bash
cd portfolio && python3 -m http.server 8000
```

Then visit http://localhost:8000.

## What's inside

```
portfolio/
├── index.html   content
├── style.css    styling (colors and fonts are variables at the top)
├── script.js    scroll reveal
├── photo.png    portrait
└── README.md    full guide, including the design choices
```

See [`portfolio/README.md`](portfolio/README.md) for the palette, fonts and concept, and how to change them.
